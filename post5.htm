5. System Performance-ii

Command: Get-Process | Sort-Object WorkingSet -Descending | Select -First 10

How to run it: Type the command line and press Enter.

What it does: Lists the top 10 processes using the most memory (RAM). High memory usage can force the system to use the disk as "virtual memory" increasing latency.

6. System Performance-iii

Command: Get-Counter "\PhysicalDisk(_Total)\Avg. Disk Queue Length"

How to run it: Type the command and press Enter. Run it while your laptop feels slow to get a useful reading.

What it does: Measures the average disk queue length. A consistently high number (e.g. >2 for a single disk) indicates the disk is overloaded and a performance bottleneck.

7. System File Integrity

Command: sfc /scannow

How to run it: Type sfc /scannow in PowerShell and press Enter. (Note: Run this in an administrator PowerShell window).

What it does: While technically a Command Prompt (CMD) tool, it's essential for system health. It scans and repairs protected Windows system files. Corruption here can cause strange system behavior.

📝 Recap: How to Use This Information

Here is a simple action plan based on what you might find:

  • If Get-PhysicalDisk shows "Warning" or "Unhealthy": This confirms your earlier findings and suggests the drive may need replacement soon.
  • If Repair-Volume finds errors: Run the command with -OfflineScanAndFix to repair them, which should improve system stability.
  • If a specific process (like Antimalware Service Executable or a browser) consistently tops the CPU/memory lists: That program is the likely cause of the slowdowns you are experiencing.
  • If sfc /scannow finds corrupt files: It will attempt to repair them automatically. This can resolve deep-seated OS issues.
