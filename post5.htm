PowerShell Toolkit for PC System Repair-2

Some useful PowerShell commands and the way how you can easily run them and their effects.

📁 Automation 📅 August 1, 2026 ⏱ 7 min read

🛠 Key PowerShell Commands for you to Diagnose your or your friends laptops and desktop computers.

Here's what it does, why I built it, and how you can use it too.

1. Disk & File System Health-I

Command: Get-PhysicalDisk

How to run it: Type Get-PhysicalDisk and press Enter. Look at the HealthStatus column.

What it does: Provides a quick overview of all physical drives, including their HealthStatus (Healthy, Warning, Unhealthy) and OperationalStatus . This confirms the disk's status from the system's perspective.

2. Disk & File System Health-II

Command: Get-Volume

How to run it: Type Get-Volume and press Enter. Check the HealthStatus column for any not Healthy

What it does: Checks the health and space allocation of your logical drives (C:, D:, etc.). It can reveal file system errors that the physical disk check might miss.

3. Disk & File System Health-III

Command: Repair-Volume -DriveLetter C -Scan

How to run it: Type the Command line and press Enter.

What it does: Scans the specified drive (C: in this example) for file system corruption. If issues are found, you can run it with -OfflineScanAndFix to repair them, which usually requires a reboot.

4. System Performance

Command: Get-Process | Sort-Object CPU -Descending | Select -First 10

How to run it: Type the Command line and press Enter.

What it does: Lists the top 10 processes currently using the most CPU resources. This helps identify if a specific program is causing slowdowns or high latency.
